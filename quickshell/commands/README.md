# Свои команды

Сюда кладутся скрипты, которые должны появиться в меню «Запуск
приложений» (и в поиске по Super+Space).

Имя файла — то, что увидите в списке: обновить_погоду.sh покажется как
«обновить погоду». Первая строка файла, если она начинается с #, станет
пояснением.

Пример — скриншот_окна.sh:

    # Снимок активного окна
    python3 ~/.config/quickshell/scripts/shot.py window

Скрипт выполняется в терминале. Файлы с правами на исполнение не нужны —
запускаем через sh.
